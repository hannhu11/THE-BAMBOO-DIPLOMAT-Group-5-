# Prompt P5 — UI mockup

## Công cụ
Gemini 2.5 Pro

## Prompt

```
Design a mobile-first web UI for a Vietnamese Ho Chi Minh Thought course
minigame. The UI shows:
- 3 options (A/B/C) as radio buttons
- An "All-in" toggle for underdogs
- 2-3 card slots (Anchor / Alliance / Veto)
- A "Confirm" primary button

Aesthetic:
- Dark green bamboo #0F2A22 background
- Bronze gold #C79B3A accent
- Vietnamese diacritics — Be Vietnam Pro font
- 320px min width

Return HTML + CSS only, no framework.
```

## Chỉnh sửa

- AI xuất pixel-perfect Tailwind — nhóm chuyển sang CSS thuần cho nhẹ.
- AI dùng emoji trong tiêu đề — nhóm bỏ (giữ tính học thuật).
- Nhóm tự thêm reduced-motion.
